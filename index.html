Perangkat yang membagikan layar

Buka halaman ini pada perangkat target. Buat kode sesi, lalu kirim kode kepada perangkat pengendali. Berbagi layar baru dimulai setelah Anda menyetujuinya.

Permintaan akses masuk

Perangkat lain ingin melihat layar dan mengirim peristiwa input ke halaman web ini. Setujui hanya jika Anda mengenal pengakses.

Perangkat pengendali

Masukkan kode sesi dari perangkat target. Kode hanya berlaku untuk satu sesi.

Kontrol input di versi ini hanya dikirim sebagai peristiwa ke halaman web pendamping. Tidak mengendalikan desktop/Android secara menyeluruh.

Belum terhubung.

Demo kontrol tidak menjalankan perintah OS dan tidak dapat menekan tombol pada aplikasi lain. Untuk kendali desktop penuh dibutuhkan agent native yang dipasang dan diizinkan secara eksplisit.

Keamanan: gunakan HTTPS/WSS saat dipasang online. Jangan bagikan kode sesi kepada orang yang tidak dipercaya. Tutup sesi setelah selesai.
